# Создание бота в MAX

Инструкция актуальна для подключения бота MAX к приложению инвестиционного портфеля.

## 1. Создать профиль

1. Откройте платформу MAX для разработчиков: https://dev.max.ru/docs/chatbots/bots-create
2. Создайте и верифицируйте профиль организации, ИП или самозанятого.
3. Учитывайте ограничение MAX: обычное физлицо не может создать чат-бота. Для юрлица/ИП доступно до 5 ботов, для самозанятого до 2.

## 2. Создать бота

1. В профиле откройте раздел `Чат-боты`.
2. Нажмите `Создать`.
3. Заполните карточку бота:
   - название;
   - логотип 500x500;
   - описание до 200 символов;
   - сайт и телефон, если нужны.
4. Ник бота MAX генерирует автоматически, вручную выбрать его пока нельзя.
5. Отправьте бота на модерацию.

По документации MAX модерация занимает до 48 часов по рабочим дням. Статус виден в карточке бота, уведомления приходят от `MAX для бизнеса`.

## 3. Получить токен

После успешной модерации откройте:

`Чат-боты` -> `Перейти` -> `Расширенные настройки` -> `Настроить`

В этом разделе будет токен бота.

Токен нужно хранить только в переменных окружения сервера:

```env
MAX_BOT_TOKEN=your_max_bot_token
```

Не сохраняйте токен в Git, README, issue, чатах или клиентском коде.

## 4. Подключить к приложению

В интерфейсе приложения:

1. Откройте `/settings`.
2. Найдите блок `MAX`.
3. Установите статус `Enabled`.
4. Выберите получателя:
   - `User ID`, если отправка идет пользователю;
   - `Chat ID`, если отправка идет в чат.
5. Заполните соответствующее поле.
6. Нажмите `Сохранить MAX`.
7. Нажмите `Тестовая отправка`.

## 5. Smoke-проверка из консоли

Из папки `app`:

```powershell
$env:MAX_BOT_TOKEN="..."
$env:MAX_USER_ID="..."
npm run smoke:max
```

Или для отправки в чат:

```powershell
$env:MAX_BOT_TOKEN="..."
$env:MAX_CHAT_ID="..."
npm run smoke:max
```

Smoke-скрипт маскирует id получателя и не печатает токен.

## 6. Как получить user_id или chat_id

Для разработки можно использовать Long Polling `GET /updates`.

Для production MAX рекомендует Webhook через `POST /subscriptions`.

После того как пользователь запустит бота или бот будет добавлен в чат, в событиях можно увидеть нужный `user_id` или `chat_id`.

## 7. API-заметки

- Базовый URL API: `https://platform-api2.max.ru`
- Токен передается в заголовке `Authorization`.
- Текстовое сообщение отправляется через `POST /messages`.
- Для адресации используется query-параметр `user_id` или `chat_id`.
